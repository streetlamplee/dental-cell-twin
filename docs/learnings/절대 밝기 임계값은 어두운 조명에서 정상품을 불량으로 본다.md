# 절대 밝기 임계값은 어두운 조명에서 정상품을 불량으로 본다

## 관측 (Day 9 2차, seed 42, 보정은 default 조명 seed 1)
| 조건 | FP | 판정 이유 (`inspections.csv`) |
|---|---|---|
| KFL08 dark | **29/29 정상품** | `hue match 0.97~0.99 ≥ 0.797; interior bright 0.00 < 0.156` → shape(누락) |
| crown dark | 2/29 | `contour dist 0.005/0.013 (max 0.02), area ratio 0.95 (tol 0.05)` |
| box dark | 0 | hue와 채도만 써서 영향 없음 |

## 원인
- **KFL08 누락 검사**는 제품 내부에서 `V ≥ bright_v_min(140)`인 픽셀 비율을 본다. 이 값은 **절대 밝기**다. 조명이 35 %로 줄면 정상 베어링 안쪽도 140을 넘지 못해 비율이 0이 된다.
- **크라운 분할**은 벨트보다 밝은 픽셀(`bright_delta`)을 쓴다. 어두우면 그림자 쪽 가장자리가 빠져 면적이 약 5 % 줄고(5336 → 5073 px), 면적비 허용치 ±5 %의 경계에 걸린다.
- 색(hue, a*b*)은 밝기에 비교적 둔감해서, 세 제품 모두 색 점수는 정상이었다.

## 결론
- 오류는 모두 **안전 쪽**(정상품을 불량으로 판정)이었다. 결함을 놓친 경우는 0건이다.
- 조명이 바뀌는 환경에서는 절대 밝기 임계값 대신 **상대값**(제품 영역 밝기의 백분위, 또는 배경 대비)을 써야 한다. 그렇지 않으면 조명별로 보정해야 한다.
- 평가 run(seed 42)을 보고 임계값을 고치면 평가가 오염된다. 고친다면 새 보정 기준을 정한 뒤 **다른 seed**로 다시 평가한다. 지금은 고치지 않고 README Known Issues에 그대로 공개했다.
