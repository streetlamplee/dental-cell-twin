# 궤적 샘플링과 충돌 사전 검사

IK가 경유점에 도달하더라도 경유점 사이의 관절 공간 보간은 장애물을 통과할 수 있다. 실제 `ArmTransfer.state()`와 `CellCycle.pose_at()`를 샘플링해 [[형상 경계와 OBB 충돌 검사]]를 적용한다.

샘플은 시작·끝·모든 경유점을 포함한다. 시간 간격 최대 1/120 s, 관절별 회전 증가량 최대 1도, 직선 관절 증가량 최대 2 mm를 기본으로 한다. smoothstep의 최대 도함수 1.5를 사용해 구간의 샘플 개수를 정한다. 이는 관절 증가량 제한이며 링크 표면의 최대 이동거리나 연속 충돌 무검출을 보장하지 않는다.

로딩은 기계 `load_pose`, 언로딩은 `unload_pose`에서 검사한다. 기계 사이클 전체는 로봇의 열린 그리퍼 대기 자세와 비교한다. [[시뮬레이션 시각과 캡처 추적]]의 실제 벽시계·렌더 지연과 별도로, 궤적의 시뮬레이션 시각을 사용한다. 보고서는 phase별 형상 쌍의 최초 검출 시각·관절값·중심 위치와 샘플 수를 남긴다.

샘플에서 박스가 겹치지 않은 결과는 `clear_at_samples`, 겹침이 발견된 결과는 `blocked_potential_collision`이다. [[로봇 충돌 검사 범위와 차단 정책]]에 따라 실행을 차단하며 자동 회피 경로를 생성하지 않는다. 실제 구현과 재현 명령은 [[2026-10-30 로봇 충돌 사전 검사 구현]]을 참고한다.
