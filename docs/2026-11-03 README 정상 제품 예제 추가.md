# 2026-11-03 README 정상 제품 예제 추가

## 구현

- `record_clips.ps1 -Example good`: seed를 생략하면 42를 사용하고 정상 GIF는 `docs/screenshots/clips/good/`에 저장한다. 기존 불량 GIF를 덮어쓰지 않는다.
- 기본 `-Example defect`는 seed 3을 유지한다. 명시적으로 지정한 seed는 존중한다.
- `record_clips.py`: 정상 통과 클립 05_pass 추가. 실제 분류 결정을 우선한다.
- [[정상과 불량 예제의 판정 및 분류 검증]]으로 요청 종류와 실제 제품·판정·분류가 일치하지 않으면 녹화를 성공 처리하지 않는다.
- `render.json`에 실제 예제 결과와 run_id를 기록하며 원본 `inspections.csv`와 함께 GIF 옆에도 보존한다.
- 정상 예제는 단일 제품으로 녹화하고 검사·확대 뷰포트를 순차 재사용한다. GPU 공유 상태에서 세 번째 뷰포트의 메모리 부담을 줄이되 1280×720 MP4, 960×540 GIF와 고정 스텝은 유지한다. 불량 녹화의 독립 확대 뷰포트 구성은 유지한다.
- 테스트는 정상 판정의 통과 클립 선택, SORTED 제품의 추가 촬영, 실제 배출 결정 우선, 불량 판정의 배출 클립 선택을 확인한다.
