# 형상 경계와 OBB 충돌 검사

OBB는 형상을 감싸는 방향성 박스다. 각 USD Boundable의 로컬 경계와 합성된 월드 변환으로 중심·반길이·방향을 구한다. CAD의 mm/m 스케일, 메시 원점, 참조와 인스턴스 프록시를 포함하며, 비활성/숨김 형상은 제외한다. 로봇·기계 링크의 강체 프레임에 저장한 박스를 FK로 이동시킨다. 시어와 잘못된 경계는 오류로 처리한다.

[[USD 합성과 변환 계층]]의 합성 변환을 사용하므로 원본 USD는 수정하지 않는다. 큰 링크 하나의 경계 대신 각 형상마다 박스를 만들어 빈 공간까지 합쳐지는 정도를 줄인다. 원통·곡면·메시에는 여전히 과대 경계가 생긴다.

AABB broad phase에서 후보를 줄인 뒤 SAT로 검사한다. 검사 축은 두 박스의 면 법선 6개와 모서리 축의 외적 9개다. 어느 축에서라도 투영 구간이 분리되면 간섭 없음이다. 접촉은 간섭으로 취급한다. `margin`은 두 박스를 각각 로컬 축으로 절반씩 확장하는 정책이며 정확한 유클리드 최소 거리 계산이 아니다.

[[궤적 샘플링과 충돌 사전 검사]]에서 이 연산을 반복한다. 박스 겹침은 잠재 간섭이며 정밀 메시 접촉과 구분한다. 구현·검증 기록은 [[2026-10-30 로봇 충돌 사전 검사 구현]]에 있다.
