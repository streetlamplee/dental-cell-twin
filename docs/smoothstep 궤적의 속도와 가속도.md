# smoothstep 궤적의 속도와 가속도

현재 로봇 이송과 검사 기계는 경유점 사이를 3차 smoothstep으로 보간한다. 구간 길이 T, 변위 Δq, 정규화 시간 u=(t-t0)/T에서 다음과 같다.

```text
q = q0 + Δq (3u² - 2u³)
v = Δq (6u - 6u²) / T
a = Δq (6 - 12u) / T²
|v|max = 1.5 |Δq| / T       (구간 중간)
|a|max = 6 |Δq| / T²        (구간 양끝의 편측 극한)
```

회전축은 rad/s, rad/s², 직선축/그리퍼는 m/s, m/s²다. 속도는 경유점에서 0이지만 가속도는 이어지는 구간에서 불연속일 수 있다. 따라서 가속도 크기의 유한한 구간별 최대값과 이상적인 jerk의 비유계성을 구분한다.

위치가 순간 초기화되는 경계에는 구간 내부의 유한한 속도·가속도 공식을 적용할 수 없다. continuous 축의 정확한 2π 래핑은 물리 방향이 같지만, 직선축 위치 점프는 실제 불연속이다. 실제 제어기로 옮길 때는 연속 각도 표현과 복귀 궤적을 따로 처리해야 한다.

[[궤적 샘플링과 충돌 사전 검사]]는 형상 간섭을 조사하고 이 계산은 시간 제약을 조사한다. 둘은 별개다. [[URDF 운동 제한의 검증 범위]]에 따라 제한 누락을 합격으로 해석하지 않는다. 구현·결과는 [[2026-11-01 관절 속도와 가속도 검증]]에 연결한다.

시간 재배분은 `T_new = max(T_original, 1.5 |Δq|/v_limit)`를 각 확인된 제한에 적용한다. 알려진 가속도 제한이 있다면 `sqrt(6 |Δq|/a_limit)`도 하한이 되지만, 현재 자산에는 가속도 제한이 없어 적용하지 않는다. [[검사 셀 복귀와 시간 배분 정책]]에 따라 정지/이송 시간은 유지하고 이동 시간만 늘린다.
