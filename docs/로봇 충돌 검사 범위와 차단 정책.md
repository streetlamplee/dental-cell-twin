# 로봇 충돌 검사 범위와 차단 정책

요청: 포트폴리오 고도화 중 충돌 검사부터 구현한다. 첫 범위는 기존 USD 자산과 키네마틱 궤적을 그대로 사용한 로봇-주변 형상의 충돌 사전 검사로 정한다. Kit 없이도 재현할 수 있도록 수학은 numpy, 형상 추출은 usd-core 어댑터로 분리한다.

[[형상 경계와 OBB 충돌 검사]]와 [[궤적 샘플링과 충돌 사전 검사]]를 조합한다. 대상은 로봇 링크/그리퍼와 기계·검사 카메라·고정구·컨베이어·바닥·받침대·기타 팩토리 형상이다. 로봇 루트 링크와 장착 받침대의 접촉만 명시적으로 제외한다.

자체 충돌, 운반 제품, 기계와 환경 사이의 간섭, 수동/티칭 이동, PhysX 접촉, 메시 정밀 검사, 연속 충돌 검사, 자동 경로 회피는 이번 구현의 대상이 아니다. 보수적인 박스 겹침도 실행 차단 사유로 남기고 임의 허용하지 않는다.

`Build Scene`에서 신규 합성 장면을 검사한다. IK 캐시를 사용해도 검사는 생략하지 않는다. 잠재 간섭이면 장면 준비를 완료하지 않고 `Start`도 차단한다. 형상 추출 오류를 간섭 없는 결과로 바꾸지 않는다. 장면 편집 후 자동 재검사는 없으므로 `Build Scene`을 다시 실행해야 한다. 기존의 로봇 자산 부재 시 포물선 이송 대체 동작은 유지하며 그 경우 로봇 충돌 검사는 수행되지 않는다.
