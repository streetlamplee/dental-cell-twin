# Kit 110.4.0 kit_base_editor 기반 앱 구성

## 요약
이 저장소 루트에 `kit-app-template` **110.4.0 브랜치**를 받고, `kit_base_editor` 템플릿으로 `visiontwin.app`을, Python UI 템플릿으로 `visiontwin.factory` 확장을 만든다.

## 선택지와 결정
| 항목 | 선택 | 이유 |
|---|---|---|
| 템플릿 위치 | 이 폴더에 새로 받기 | 포트폴리오 저장소를 독립적으로 유지 (기존 `usd_converter`와 분리) |
| 버전 | `110.4.0` 브랜치 고정 | `main`은 계속 바뀌므로 재현성을 위해 릴리스 브랜치 고정 |
| 앱 템플릿 | `kit_base_editor` | Viewport, Stage, Property, omni.ui 포함. `usd_composer`보다 가벼워 VRAM 8GB에 적합 |
| 확장 템플릿 | `basic_python_ui_extension` | omni.ui 패널과 테스트 골격 포함 |

## 계획서와 달라진 점
- 계획서의 `exts/visiontwin.factory/`는 템플릿 규칙에 따라 `source/extensions/visiontwin.factory/`에, `apps/visiontwin.kit`는 `source/apps/visiontwin.app.kit`에 둔다.
- 시뮬레이션 로직은 `visiontwin/factory/core/` 패키지로 분리한다. 이 패키지는 `omni`와 `pxr`를 import하지 않으므로 Kit 없이 pytest로 검증할 수 있다. → [[2026-10-21 Day2 컨베이어 시뮬레이션과 제품 상태 머신]]
