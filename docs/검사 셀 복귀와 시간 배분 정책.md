# 검사 셀 복귀와 시간 배분 정책

[[2026-11-01 관절 속도와 가속도 검증]]에서 확인된 X/Y 속도 초과와 사이클 끝 위치 점프를 수정한다. 기존 이동 시간을 최소값으로 삼고, [[smoothstep 궤적의 속도와 가속도]]의 `T >= 1.5 |Δq| / v_limit`으로 필요한 만큼만 연장한다. 정지·로봇 이송 시간과 검사 시점 자세는 유지한다.

기계 속도 제한은 원본 URDF에서 kinematics JSON으로 전달한다. 기존 JSON은 속도가 없으면 None으로 읽을 수 있지만 현재 기계 자산은 X/Y/Z의 0.1 m/s를 포함한다. [[URDF 운동 제한의 검증 범위]]대로 제한이 없는 축에 임의 값을 넣지 않는다. 알려지지 않은 가속도 제한도 추정하지 않는다.

언로딩이 끝난 뒤 빈 기계를 초기 자세로 보간하는 RETURNING 구간을 추가한다. X뿐 아니라 C의 회전도 궤적 안에서 0으로 돌려 끝점 초기화 자체를 없앤다. 이때 로봇은 대기 자세이고 제품은 이미 내려놓은 출구 위치에서 대기한다. `ProcessStation.cycle_s`에 복귀 시간을 포함해, 기계 복귀가 끝나야 제품의 컨베이어 이동과 다음 투입을 허용한다. 출구 해제와 셀 준비를 분리하는 파이프라이닝은 이번 범위에 넣지 않는다.

복귀 경로도 기존 로봇-환경 충돌 사전 검사에 포함한다. 충돌 없음과 속도 적합성은 서로 대체하지 않는다. 결과는 [[2026-11-01 검사 셀 복귀와 속도 기반 시간 재배분]]에 남긴다.
