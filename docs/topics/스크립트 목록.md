# 스크립트 목록

`scripts/`의 모든 스크립트는 프로젝트 루트 어디서 실행해도 된다. 실행 로그는 `logs/`(git 제외)에 남는다.

## 터미널별 실행 방법
| 터미널 | 명령 |
|---|---|
| PowerShell | `.\scripts\launch_app.ps1` |
| Git Bash / cmd | `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/launch_app.ps1` |

- Git Bash에서 `.\scripts\...`라고 치면 `\`가 사라져 `command not found`가 난다. 또 bash는 `.ps1`을 직접 실행하지 못한다.
- PowerShell에서 "이 시스템에서 스크립트를 실행할 수 없으므로…"(`PSSecurityException`)가 나면, 실행 정책이 기본값 `Restricted`이기 때문이다. 둘 중 하나를 쓴다.
  - 매번 우회: `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\<script>.ps1`
  - 한 번만 설정(관리자 권한 불필요): `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`

| 스크립트 | 목적 | 언제 |
|---|---|---|
| `setup_kit_template.ps1 [-Branch 110.4.0]` | kit-app-template을 루트에 받기 | 최초 1회 |
| `list_templates.ps1` | 템플릿 목록 (대화형 UI라 Agent 셸에서는 실패) | 참고용 |
| `new_from_template.ps1 -PlaybackFile <toml>` | replay 파일로 앱/확장 생성 | 앱/확장 추가 시 |
| `build_app.ps1` | `repo.bat build` | 최초, 앱/확장 추가 시 |
| `launch_app.ps1` | VisionTwin GUI 실행 | 수동 확인, 시연 |
| `render_smoke.ps1 [-Frames 240]` | GUI 앱 자동 실행 → 씬 생성 → Viewport PNG 저장 → 종료 (`render_smoke.py` 사용) | 씬/조명/카메라 수정 후 |
| `probe_capture.ps1` | Gate B 진단: 검사 카메라 버퍼 캡처 성공 여부 (`probe_capture.py`) | 캡처/렌더 관련 수정 후 |
| `collect_frames.ps1 [-Seed 42] [-Products 30] [-Speed 0.5]` | 1회 전체 run: 프레임, 실시간 판정, 배출 → inspections.csv, results.csv, summary.json (`collect_frames.py`) | 데이터 수집, 실험 |
| `compare_runs.ps1 -RunA <a> -RunB <b>` | 두 run의 results.csv 결정론적 컬럼 비교(재현성) | 같은 시드 재실행 후 |
| `setup_cad_env.ps1` | CAD용 venv(.venv-cad: cadquery, usd-core) | 최초 1회 |
| `urdf_to_step.ps1 [-Urdf]` | URDF → STEP 어셈블리(mm, 색) + kinematics.json | URDF 변경 시 |
| `probe_cad_converter.ps1 -Stp <f>` | Gate C 진단: USD converter로 STP 1개 변환, 구조 출력 | 변환기 문제 조사 |
| `convert_step_to_usd.ps1 -Stp <f> [-Out]` | USD converter(HOOPS)로 STEP → USD (`config/cad_converter_options.json`) | STP 변경 시 |
| `verify_cad_usd.ps1 [-Name]` | 변환 USD를 URDF와 비교(이름, 위치, bbox, 색) | 변환 후 매번 |
| `calibrate_inspector.ps1 -RunDir <보정 run>` | 정상품 프레임으로 기준 색상/채도 결정 → `config/inspector.json` | 조명/색 변경 후 (seed 1 run 사용) |
| `inspect_frames.ps1 [-RunDir] [-Config]` | 저장된 프레임 오프라인 재판정, 지표, 오검출 오버레이 | 수집 후 평가 |

Kit 자동화 스크립트는 `_common.ps1`의 `$KitAutomationArgs`(크래시 창 없음, 저장 확인 없음)를 쓴다. 다른 `kit.exe`가 실행 중이면 경고만 한다.
| `test_core.ps1 [-Filter expr]` | Kit 없는 pytest(`tests/`) | 로직 수정 후 매번 |
| `test_ext.ps1` | Kit 내부 확장 테스트(헤드리스) | Kit 코드 수정 후 |
| `_common.ps1` | 공통 헬퍼(직접 실행 X) | — |

## 처음부터 재현하기
```powershell
.\scripts\setup_kit_template.ps1
.\scripts\build_app.ps1
.\scripts\test_core.ps1
.\scripts\test_ext.ps1
.\scripts\render_smoke.ps1
.\scripts\launch_app.ps1
```
(이 저장소에는 이미 앱과 확장이 포함되어 있으므로 `new_from_template.ps1`은 다시 실행하지 않는다.)
