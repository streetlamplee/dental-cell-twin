# 데모 촬영 샷리스트 (90~120초 목표, 2026-10-24 개정)

**주제:** "치아 크라운 가공 셀 디지털 트윈: CAD에서 가져온 5축 기계와 Seeed 로봇이 한 라인으로 돌고, 필요하면 기계가 카메라를 들고 다섯 방향에서 검사한다"

## 준비
1. 다른 GPU 프로그램을 닫는다. 녹화 도구: Win+Alt+R(Xbox Game Bar) 또는 OBS, 1920×1080
2. `.\scripts\run_demo.ps1` (기본: 크라운 4개, seed 42 → #2 셰이드 결함, #3 치핑)
   - 첫 실행은 셰이더 준비로 느리다. 리허설을 한 번 한 뒤 다시 실행해서 녹화한다
3. 전체 화면(Overview)이 뜨면 녹화를 시작한다. 이후에는 화면이 자동으로 바뀐다:
   - 로봇 로딩·언로딩 → 셀 근접
   - 기계 촬영 → 스핀들 카메라
   - 그 밖 → 전체
   - 마지막에 티칭 펜던트가 원점 + 5면을 재생한다
4. 렌더와 시뮬레이션이 동기라서 실제보다 느리게(슬로모션) 진행된다. 편집할 때 1.5~2배속으로 맞춘다.

## 샷 구성 (편집 기준)
| # | 길이 | 화면 (자동) | 보여 줄 것 | 자막 예시 |
|---|---|---|---|---|
| 1 | 0–8 s | Overview | 정지한 라인 전체: 투입 벨트, 검사 셀(5축 기계), 로봇, 배출 벨트, bin | "URDF·STEP을 USD로 가져온 치아 가공 셀 (Omniverse Kit)" |
| 2 | 8–25 s | 셀 근접 | reBot Arm이 벨트 끝에서 크라운을 집어 플래터로 옮김 | "Seeed reBot Arm: 6축 IK, 수직 하향 파지" |
| 3 | 25–45 s | 스핀들 카메라 | B 45° 기울임 + C 회전으로 윗면·옆면 4장 촬영 (Inspection Camera 창도 함께) | "기계가 카메라를 들고 5시점 검사 (선택 기능)" |
| 4 | 45–55 s | 셀 근접 → 전체 | 언로딩 → 배출선에서 불량(#2 분홍, #3 치핑)을 푸셔가 bin으로 | "제품 ID 기반 분류" |
| 5 | 55–65 s | 대시보드 확대 | 셀 상태(LOADING / VIEW k/5 / UNLOADING), 대기열, 가동률, 분류 수 | "셀 사이클 8.2 s, 가동률·대기열 측정" |
| 6 | 65–90 s | 티칭 근접 | 티칭 펜던트가 원점 + 블록 5면을 재생 (B −90°, C 0/90/180/270°) | "실제 가공기 티칭을 재현: 공구가 각 면을 수직으로" |
| 7 | 90–110 s | 정지 이미지 | `docs/screenshots/readme_views.png`(치핑은 측면에서만), `readme_fig_model.png`(어두운 조명 오판정 29 → 0) | "실측 결과 그대로" |

## 주의
- 셀 사이클과 기계 치수는 시연용 값이다(README에 명시).
- 화면의 수치는 실제 run 값만 쓴다. 편집으로 꾸미지 않는다.
- 검사를 빼고 찍으려면, 대시보드 "Vision"을 끄고 Build Scene → Start로 직접 진행한다(3번 샷 생략).
