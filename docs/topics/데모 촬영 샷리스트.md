# 데모 촬영 샷리스트 (90초 목표)

**주제:** "치아 밀링 가공 라인 디지털 트윈: 블랭크가 크라운이 되고, 카메라가 검사하고, 불량은 밀려난다"

**준비:** `launch_app.ps1` → 대시보드 Product = **Dental crown (mill line)**, Seed 42, Products 20, Defect rate 0.3 → Build Scene. 화면 녹화(Win+Alt+R 또는 OBS) 1920×1080. 녹화 전에 한 번 실행해서 셰이더를 미리 컴파일해 둔다.

|---|---|---|---|---|
| 1 | 0–8 s | Overview | 정지 상태의 라인 전체: 컨베이어, 밀링기, 검사선, 배출 bin | "CAD에서 만든 공장 라인 (OpenUSD / Omniverse Kit)" |
| 2 | 8–15 s | Overview | Start. 블랭크가 들어온다 | "블랭크 투입" |
