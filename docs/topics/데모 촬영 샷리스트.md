# 데모 촬영 샷리스트 (90초 목표)

**주제:** "치아 크라운 인라인 검사 라인: 5축 기계가 카메라를 들고 크라운을 다섯 방향에서 보고, 불량은 밀려난다"

**준비:** `launch_app.ps1` → 대시보드 Product = **Dental crown (inspection cell)**(기본값), Seed 42, Products 20, Defect rate 0.3 → Build Scene. 화면 녹화(Win+Alt+R 또는 OBS) 1920×1080. 녹화 전에 한 번 실행해서 셰이더를 미리 컴파일해 둔다. seed 42에서는 #2가 셰이드 결함, #3이 치핑이다(평가 run 기준).

| # | 시간 | 화면 (View 콤보) | 할 일 / 보여 줄 것 | 자막(선택) |
|---|---|---|---|---|
| 1 | 0–8 s | Overview | 정지 상태의 라인 전체: 투입 컨베이어, 검사 셀, 배출 컨베이어, bin | "CAD에서 만든 한 줄 라인 (OpenUSD / Omniverse Kit)" |
| 2 | 8–15 s | Overview | Start. 크라운이 들어와 셀 입구에서 멈춘다 | "투입 → 셀 입구 대기" |
| 3 | 15–40 s | **Cell close-up** | 로딩 → 카메라가 내려와 윗면 → B 45° 기울임 + C 회전으로 옆면 4번 → 카메라가 비키고 언로딩 | "5축 기계(URDF → STEP → USD converter)를 검사 셀로: 스핀들에 카메라" |
| 4 | 40–55 s | **Inspection camera** (+ Inspection Camera 창) | #3 치핑: 윗면은 정상처럼 보이고, 측면 A에서 노치가 보인다 | "위에서 안 보이는 결함을 옆면 시점이 잡는다" |
| 5 | 55–68 s | Overview | 불량(#2 분홍 셰이드, #3 치핑)을 푸셔가 bin으로 민다 | "제품 ID 기반 자동 분류" |
| 6 | 68–80 s | 대시보드 확대 | 카운터: vision good/defect, sorted correct, **cell VIEW k/5 / queue / util** | "셀 가동률·대기열 측정" |
