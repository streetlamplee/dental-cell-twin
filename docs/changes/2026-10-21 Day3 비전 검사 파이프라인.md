# Day3 비전 검사 파이프라인

## 요약
제품이 검사선을 지나면 검사 카메라의 **렌더 프레임**을 받아 OpenCV 규칙 기반 색상 검사로 `good / defect / unknown`을 판정한다. 프레임과 결과는 run 폴더에 저장한다. 같은 프레임을 Kit 없이 다시 판정하고 평가하는 오프라인 도구도 만들었다.

## 흐름
```
ConveyorSim INSPECT 이벤트 ──> InspectionFrameProvider.request_frame()  (검사 카메라 Viewport, 640x480)
                                   └─ 버퍼 콜백: RGB ndarray ──> VisionInspector.inspect(rgb)  (픽셀만 입력)
                                                                   └─ product.prediction 저장
                                                                   └─ InspectionLog: frames/P_xxxx.png + inspections.csv
```

## 새 파일
| 파일 | 내용 |
|---|---|
| `core/vision_inspector.py` | HSV 변환 → ROI → 채도/밝기 마스크 → 가장 큰 덩어리 → 기준 색상과의 일치 비율(score) → 판정. 덩어리가 없으면 `unknown` |
| `core/camera_model.py` | 핀홀 모델. 카메라 높이, 초점거리, 조리개로 검사 ROI(벨트 폭 × 검사 창)를 계산 |
| `core/inspection_log.py` | run별 PNG와 CSV 기록. CSV 필드는 계획서의 필수 필드에 맞춤 |
| `core/metrics.py` | confusion, precision/recall/F1, percentile (Day 6에서도 사용) |
| `frame_provider.py` | Gate B 구현. [[검사 카메라 프레임 캡처 (Gate B)]] |
| `scripts/collect_frames.*` | GUI 앱을 자동 실행해 1회 전체 run을 기록 |
| `scripts/inspect_frames.*` | 저장된 프레임을 오프라인으로 다시 판정 → `offline/predictions.csv`, `offline/errors/` |
| `scripts/calibrate_inspector.*` | 보정용 run의 정상품 프레임으로 기준 색상과 채도 임계값 결정 → `config/inspector.json` |
| `scripts/probe_capture.*` | Gate B 진단 |

## 설계 원칙
- **ground truth 분리:** `VisionInspector.inspect`의 인자는 `rgb` 하나뿐이다(테스트로 강제). 정답은 tracker에서 CSV로만 복사되어 평가에 쓰인다.
- **보정과 평가 분리:** 보정은 seed 1 run, 평가는 seed 42 run으로 한다.
- **OpenCV 설치:** Kit에는 `[python.pipapi]`로 `opencv-python-headless==4.13.0.92`를 `--no-deps`로 설치한다(Kit 내장 numpy 2.3.1 유지). Kit 문서상 런타임 pip 설치는 프로토타입용이므로 한계로 기록한다.
- **씬 변경:** 검사선/배출선 표시를 벨트 위 띠에서 **벨트 옆 기둥**으로 옮겼다. 검사 ROI에 들어오지 않게 하기 위해서다.

## 앱 설정 변경
- `rtx.ecoMode.enabled = false`: 매 프레임 렌더(캡처의 신선도 확보)
- `exts."visiontwin.factory".outputDir / inspectorConfig`: 저장소의 `results/`, `config/inspector.json`

### 해석 (과장 금지)
- 현재 결함은 **파랑 대 빨강**의 큰 색상 차이 한 종류뿐이다. 그래서 기본 조건에서 100%가 나오는 것은 자연스럽고, 검사기의 강건성을 보여 주지는 않는다.
- 강건성은 Day 6에서 어두운 조명, 빠른 컨베이어, (가능하면) 미세한 색 차이 결함으로 따로 측정한다.
- 30개 표본이라 신뢰구간이 넓다.
