# Day 9 실험 1차 (조명 무효)

## 추가한 것
- `experiments/day9.json`: 13개 조건
  - box, kfl08, crown 각각 × default, dark, fast (제품 40개)
  - 라인 용량 실험 `line_spawn_2.0/2.5/3.0/4.0` (crown, 20개, 가공 사이클 3 s)
- `scripts/run_experiments.ps1 -Config`: 조건마다 Kit run을 실행한다. 이미 끝난 조건은 건너뛴다. run은 `results/experiments/<name>/runs`에 저장한다.
- `scripts/analyze_results.ps1 -Experiment` (+ `.py`): `table.csv`, `table.md`, `fig_vision.png`, `fig_line.png`를 만든다.
- extension 설정 추가:
  - `lighting`(default/dark/bright → 조명 세기 배율), `cycleS`, `spawnInterval`, `experiment`, `condition`
  - `scene_manager.build_factory_scene(light_factor=...)`
- `_common.ps1`: Kit가 이미 실행 중일 때 경고하는 부분을 `Warn-IfKitRunning` 함수로 바꿨다. Kit를 실행하는 스크립트만 이 함수를 부른다.
- `render_smoke.ps1 -Lighting`와 조명 및 자동 노출 출력: 조명 문제 진단용.
- 조명 수정: `_use_stage_lights()` → [[뷰포트 자동 라이트 리그가 조명 조건을 무력화]]

## 1차 결과 (`results/experiments/day9_rig_lights/`, 뷰포트 기본 리그 조명이 켜진 상태)
- 비전: 12개 조건은 모두 정답이었다. `crown_fast`에서만 FP 1건이 나왔다. good #40의 윤곽 거리가 0.021로 기준 0.02를 넘었다. 평가 데이터로 기준을 다시 맞추지 않고 그대로 보고한다.
- **조명 조건은 무효다.** dark에서도 밝기가 3~4%만 줄어서, 강건성 근거로 쓸 수 없다.
- 라인 용량(crown, 사이클 3 s; 조명과 무관한 지표):

| 투입 간격 | 가동률 | 최대 대기 | 평균 대기 | 처리량/h |
|---|---|---|---|---|
| 2.0 s | 0.885 | 3 | 1.69 | 1061.7 |
| 2.5 s | 0.885 | 3 | 1.30 | 1061.7 |
| 3.0 s | 0.885 | 0 | 0 | 1061.7 |
| 4.0 s | 0.691 | 0 | 0 | 829.3 |

→ 투입 간격이 3 s 이하이면 밀링기가 병목이다. 간격을 줄여도 처리량은 늘지 않고 대기열만 늘어난다.
