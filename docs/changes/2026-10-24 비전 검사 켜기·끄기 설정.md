# 비전 검사 켜기·끄기 설정

## 배경
비전 검사를 남은 계획에서 뺐지만(→ [[2026-10-24 계획 마무리 - 비전 검사 제외]]), 코드에서는 계속 켜져 있었다. 사용자 요청: "설정으로 비전 검사도 할 수 있도록." 그래서 기본은 끄고, 필요할 때 켠다.

## 변경
| 파일 | 내용 |
|---|---|
| `core/sorting.py` | `SortingController(inspection=False)`: 판정 없이 모두 통과, 이유 "no inspection (vision off)" (+ 테스트) |
| `extension.py` | 설정 `vision`. 끄면 검사 Viewport·검사기·학습 모델을 만들지 않는다. INSPECT 이벤트마다 VISION "skipped (vision off)"을 기록해 감사가 맞는다. run 기록은 그대로 열린다(`run.json`/`summary.json`에 `vision`). 카운터에 "vision: off" |
| `dashboard.py` | "Vision" 체크박스(Build Scene / Reset 때 적용) |
| `visiontwin.app.kit` | `vision = false` (GUI 기본 꺼짐) |
| `collect_frames`, `bench_render`, `render_smoke` | `vision=true` 명시(이전과 같은 결과) |
| `run_experiments.ps1` | 기본 `vision=true`. 실험 설정에 `"vision": false`를 쓰면 끈다 |

확장 자체의 기본값(설정이 없을 때)은 켬이다. 그래서 Kit 테스트와 예전 명령도 그대로 동작한다. 꺼짐은 앱 설정에서만 정한다.

## 검증 (실측)
- `test_core.ps1` 99 passed, `test_ext.ps1` OK
- 크라운 3개(seed 5)
  - 꺼짐: 검사 행 0개, 프레임 0장, 모두 통과(이유 기록), 감사 OK, 41 s
  - 켜짐: 18행(5시점 + 합친 판정), 프레임 15장, 감사 OK, 60 s
