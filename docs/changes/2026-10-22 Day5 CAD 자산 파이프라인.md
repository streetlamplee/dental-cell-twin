# Day5 CAD 자산 파이프라인

## 요약
`reference/teeth_mill.urdf` → STEP(CadQuery) → USD(USD converter, HOOPS) → 공장 라인의 **가공 스테이션**까지 스크립트로 재현되게 만들었다. 관절은 `kinematics.json`으로 보존해서, 변환된 USD에 forward kinematics로 다시 적용한다.

## 재현 명령
```powershell
.\scripts\setup_cad_env.ps1                                   # .venv-cad: cadquery 2.8.0, usd-core 26.11
.\scripts\urdf_to_step.ps1                                    # -> assets/cad/teeth_mill.stp + .kinematics.json
.\scripts\convert_step_to_usd.ps1 -Stp assets\cad\teeth_mill.stp   # -> assets/cad/teeth_mill.usd
.\scripts\verify_cad_usd.ps1                                  # -> assets/cad/teeth_mill.verify.json
```

## 새/변경 파일
| 파일 | 내용 |
|---|---|
| `core/urdf_model.py` | URDF 파서(box/cylinder, 관절, 색), 홈/임의 자세 forward kinematics, `kinematics()` 내보내기, `model_from_kinematics()` |
| `core/mill_cycle.py` | 시각용 가공 사이클(관절 한계 안, 3초, 끝나면 홈) |
| `core/conveyor.py` | `stations` 설정 → `STATION` 이벤트(제품이 스테이션 선 통과) |
| `mill_station.py` | 변환 USD 참조(mm → ×0.001), 받침대, 링크 프림 transform 오버라이드로 관절 동작 |
| `extension.py` | Build Scene 시 MillStation 생성(파일 없으면 경고 후 생략), STATION 이벤트로 사이클 시작 |
| `scripts/urdf_to_step.*` | STEP 어셈블리 `<robot>/<link>/<part>`(mm, 색) + kinematics.json(관절 + 비주얼↔부품 매핑) |
| `scripts/convert_step_to_usd.*`, `config/cad_converter_options.json` | USD converter 변환. 옵션은 사용자 converter 기준이고, 색 보존을 위해 `useMaterials=true` |
| `scripts/verify_cad_usd.*` | 링크/부품 이름, 링크 위치, 부품 bbox, 색을 URDF와 비교 |
| `scripts/probe_cad_converter.*` | Gate C 진단 |
| `scripts/setup_cad_env.ps1`, `requirements-cad.txt` | 별도 venv(시스템 Python 오염 방지) |
