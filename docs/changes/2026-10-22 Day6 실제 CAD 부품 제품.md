# Day6 실제 CAD 부품 제품

## 요약
박스 대신 **실제 CAD 부품 KFL08 플랜지 베어링**(FreeCAD-library, CC-BY-3.0)을 USD converter로 변환해 컨베이어 제품으로 쓴다. 정상 / 색상 결함 / **베어링 인서트 누락** 변형을 만들고, 검사기에 **형상(인서트 유무) 검사**를 추가했다. 박스 제품은 `part=box`(기본)로 그대로 남는다.

## 재현 명령
```powershell
.\scripts\fetch_parts.ps1                                     # raw/kfl08.step (SHA256 확인)
.\scripts\convert_step_to_usd.ps1 -Stp assets\parts\raw\kfl08.step -Out assets\parts\usd\kfl08.usd
.\scripts\make_part_variants.ps1 -Part kfl08                  # usd/kfl08_{good,color,missing}.usda
.\scripts\collect_frames.ps1 -Seed 1 -Products 30 -Part kfl08 # 보정 run
.\scripts\calibrate_inspector.ps1 -RunDir results\runs\<보정 run>   # -> config/inspector_kfl08.json
.\scripts\collect_frames.ps1 -Seed 42 -Products 40 -Part kfl08 # 평가 run
.\scripts\inspect_frames.ps1 -RunDir results\runs\<평가 run>   # 결함 종류별 recall
```

## 변경 내용
| 파일 | 내용 |
|---|---|
| `assets/parts/sources.json`, `LICENSES.md` | 출처(커밋 고정 URL), SHA256, 상태/이유, CC-BY-3.0 표기와 변경 사항 |
| `assets/parts/catalog.json` | 부품 정의: 회전, 목표 크기, 도색 프림, 인서트 프림, 변형 |
| `scripts/fetch_parts.*` | 다운로드 + SHA256 기록/검증 (기본: selected만) |
| `scripts/inspect_step.*` | STEP 어셈블리 구조, 솔리드 수, 색, 크기 출력(후보 평가) |
| `scripts/make_part_variants.*` | 변환 USD를 참조하는 변형 레이어: 정규화(회전, ×4.167, 바닥 z=0), 도색 Material, 인서트 비활성 |
| `core/product_catalog.py` | 정답 라벨 → 변형 USD 경로 (box는 None) |
| `core/conveyor.py` | `defect_kinds`: 결함 종류 균등 추첨. 종류가 하나면 난수를 더 뽑지 않아 box 순서가 그대로다 |
| `core/vision_inspector.py` | 형상 검사(선택): 외곽 채움 − 블롭 = 내부, 내부 밝은 픽셀 비율 < `interior_bright_min` → shape 결함. `defect_reason` 기록 |
| `scene_manager.py` | 부품 제품은 `P_xxxx/Part` 자식에 참조. 부품별 휴지 높이 |
| `extension.py` | `part` / `partsDir` 설정, 부품별 검사 설정(`config/inspector_<part>.json`), 결과에 defect_reason. 프레임 번호가 검증되면 stale을 unknown으로 보지 않음 |
| `results.csv` | `defect_kind`(정답 결함 종류), `defect_reason`(판정 이유) 컬럼 추가 |
| `inspections.csv` | `defect_reason`, `interior_ratio`, `interior_bright` 추가 |
| `calibrate_inspector.py` | 부품이면 정상 샘플에서 `good_ratio_min`(최소×0.8), `interior_bright_min`(최소×0.5) 결정, 결과는 부품별 파일 |
| `inspect_frames.py` | 결함 종류별 recall과 판정 이유 일치 |
| `collect_frames.ps1`, `render_smoke.ps1` | `-Part` 인자 |

## 해석 (과장 금지)
- 결함 표본이 11개(색상 5, 누락 6)뿐이라 신뢰구간이 넓다.
- 기본 조명, 고정 방향, 0.5 m/s 조건이다. 형상 검사는 "보어 안의 밝은 링" 특징에 의존하므로 **조명이 바뀌면 약해질 수 있다.** Day 8 실험(어두운 조명 등)에서 측정한다.
- 도색 색은 시뮬레이션용으로 지정한 것이다(원본 STEP은 짙은 회색이라 벨트와 구분되지 않음).
