# Day7 치아 밀링 가공 라인

## 요약
밀링기가 **라인의 공정 스테이션**이 됐다.

```
블랭크 투입 → (입구 대기·축적) → 로딩(벨트 → C 플래터) → 5축 가공(블랭크 → 크라운, 3초 압축)
→ 언로딩(플래터 → 벨트) → 근접 비전 검사(셰이드 a*b*, 기준 외곽선) → 분류
```

가동률, 대기열, 처리량을 측정한다. 기존 box/KFL08 라인은 그대로다(회귀 동일).

## 재현 명령
```powershell
.\scripts\make_dental_parts.ps1                                # CadQuery -> raw/dental_*.step
foreach ($n in "dental_blank","dental_crown","dental_crown_incomplete") {
  .\scripts\convert_step_to_usd.ps1 -Stp assets\parts\raw\$n.step -Out assets\parts\usd\$n.usd }
.\scripts\make_part_variants.ps1 -Part crown                    # usd/crown_{good,color,shape}[_raw].usda
.\scripts\collect_frames.ps1 -Seed 1 -Products 30 -Part crown   # 보정 run
.\scripts\calibrate_inspector.ps1 -RunDir results\runs\<보정 run> # -> config/inspector_crown.json
.\scripts\collect_frames.ps1 -Seed 42 -Products 40 -Part crown  # 평가 run
.\scripts\inspect_frames.ps1 -RunDir results\runs\<평가 run>
.\scripts\render_smoke.ps1 -Frames 420 -Part crown              # 개요 + 밀링기 근접 + 검사 카메라
```
GUI: `visiontwin.app.kit.bat --/exts/visiontwin.factory/part=crown`, Viewport 카메라를 `MillCamera`로 바꾸면 로딩/가공이 크게 보인다.

## 변경 내용
| 영역 | 내용 |
|---|---|
| 제품 모델 | `scripts/make_dental_parts.py`: 블랭크 14×12×16, 크라운 11×10×8.3(교두 4개), 미완성 크라운(블랭크 모서리 잔존). 직접 만든 모델 |
| 변형 | `make_part_variants` 일반화: 변형마다 raw(가공 전)/final(가공 후) 원본과 도색. `paint_prims: ["*"]`(모든 메시 de-instance 후 바인딩). 실측 크기(배율 1) |
| 카탈로그 | `crown`: `process`(mill, 3초), `spawn_interval_s`, `camera`(벨트 위 0.15 m, 35 mm), `inspection`(bright/ab/golden_contour) |
| 코어 | `ProcessStation`: 입구 정지, 비어 있으면 로딩(`PROCESSING`), 사이클 후 출구가 비면 언로딩, 대기열 축적, 출구 막힘 대기. `LOAD`/`UNLOAD` 이벤트. 지표: 가동률, 바쁜 시간, 막힘 시간, 대기열 최대/평균 |
| 상태 | `MOVING → PROCESSING → MOVING` 추가 |
| 씬 | 제품 `P/Pose/{Raw,Part}`: 위치/회전 분리, 가공 중 형상 전환. 부품별 검사 카메라. `MillCamera` 근접 카메라 |
| 밀링기 | `hide_work`(URDF 기본 공작물 숨김), `platter_pose()`(B/C 회전 포함 월드 자세), 가공 사이클 길이 = 사이클의 70% |
| 확장 | 로딩(들어 올림 호) → 플래터 추종 → 중간에 크라운으로 전환 → 언로딩. 대시보드에 밀링기 상태, 대기열, 가동률. summary에 `line` 지표와 `throughput_per_hour` |
| 검사기 | `segment="bright"`(벨트보다 밝은 픽셀만, 그림자 제외), `color_metric="ab"`(Lab a*b* 셰이드), 기준 외곽선(`matchShapes` + 면적비) |
| 보정 | 카탈로그 `inspection`에 따라: 기준 a*b*, 허용치, 기준 외곽선, 거리/면적 임계값(모두 정상 샘플 + 여유) |

## 해석 (과장 금지)
- 사이클 3초는 **압축 시간**이다. 실제 크라운 가공(10분 이상)의 처리량이 아니다.
- 결함 형상이 크게 다르다(잔존 모서리로 면적 +20%). 더 미세한 가공 결함(교두 일부 누락 등)은 측정하지 않았다.
- 대기열은 이번 조건(투입 간격 = 사이클)에서 생기지 않았다. 투입 간격과 사이클을 바꾼 비교는 Day 9 실험에서 한다.
- 로딩/언로딩은 시각용 보간이다(로봇 물리 없음).
