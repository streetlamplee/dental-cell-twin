# Day2 컨베이어 시뮬레이션과 제품 상태 머신

## 요약
Kit와 독립된 `core` 패키지에 `ProductTracker`(제품 ID와 상태 머신)와 `ConveyorSim`(dt 기반 이동, 선 통과 이벤트)을 구현했다.

## 설계
- **상태:** `SPAWNED → MOVING → INSPECTED → SORTED → EXITED`, 또는 `INSPECTED → REJECTED → EXITED`. 허용되지 않은 전이는 `InvalidTransition` 예외를 던진다.
- **ID:** `ProductTracker`만 ID를 발급한다(1부터 증가). 그래서 ID가 겹칠 수 없다.
- **ground_truth:** `good` 또는 `defect`(`defect_kind="color"`). 평가 전용이다. 시드를 고정한 `random.Random(seed)`로 정한다.
- **이벤트:** `SPAWN / INSPECT / SORT / REJECT / EXIT`. 각 이벤트에는 실제 통과 시각(보간값)이 들어가고, 시간 순으로 정렬해 반환한다.
- **선 통과 판정:** 이번 스텝의 이동 구간 `x0 < line <= x1`로 판정한다. 그래서 dt가 커도 선을 건너뛰지 않는다.
- **배출 판단:** `reject_decider(product) -> bool` 콜백. 지금은 기본값이 항상 False(모두 통과)이고, Day 4에서 검사 결과와 연결한다.
- **생성 간격:** 앞 제품이 `min_gap`(0.3m)만큼 지나가기 전에는 다음 제품을 만들지 않는다(겹침 방지).

## 테스트가 잡은 버그
처음 구현에서는 생성이 막혔다가 풀린 스텝에서 새 제품을 **스텝 시작 시각부터** 이동시켰다. 그 결과 앞 제품과의 간격이 `speed×dt`만큼 줄었다(0.29m < 0.3m). 공간이 비는 시각을 역산(`_spawn_clear_time`)해 그 시각에 생성하도록 고쳤다.
