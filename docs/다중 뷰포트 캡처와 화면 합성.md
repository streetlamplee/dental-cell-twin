# 다중 뷰포트 캡처와 화면 합성

전체 설비를 보여주는 1280×720 메인 뷰포트, 검사 전용 뷰포트, 640×480 부품 확대 뷰포트를 독립적으로 유지한다. [[부품 추적 확대 렌더링]]에서 다음 제품의 검사와 대상 제품의 배출 확대를 동시에 보여주기 위해 사용한다.

[[2026-11-03 README 정상 제품 예제 추가]]의 단일 정상 제품 녹화에서는 검사와 확대가 겹치지 않으므로 640×480 뷰포트를 순차 재사용한다. 카메라 전환 중 시뮬레이션을 정지해 준비한 후 같은 시뮬레이션 시간에서 이어서 캡처한다. 정상·불량 예제 검증은 [[정상과 불량 예제의 판정 및 분류 검증]]에 기록한다.

메인 화면과 확대 화면은 같은 업데이트에서 캡처를 요청하지만 콜백 도착 순서는 보장하지 않는다. 프레임마다 두 버퍼를 묶어 보관하고 둘 다 도착했을 때만 JPEG를 저장한다. 콜백 오류나 파일 저장 실패는 누적하고, 종료 시 미완료 요청 또는 오류가 남으면 성공으로 처리하지 않는다. 시각 대응은 [[시뮬레이션 시각과 캡처 추적]]과 함께 확인한다.

캡처 RGB를 OpenCV의 BGR로 변환해 합성한다. 실시간 확대 화면은 중앙 16:9 영역을 잘라 400×225 패널로 표시하고, 검사 중에는 검사기가 실제로 저장한 가장 최근 시점의 확대 이미지와 해당 시점 이름·판정을 표시한다. 따라서 검사 패널의 저장 시점과 메인 카메라의 현재 시점이 다를 수 있으며 이를 라벨로 구분한다.

[[2026-11-02 데모 부품 가시성 개선]]의 검증에서는 실제 렌더 결과와 MP4 디코딩으로 합성과 캡처 완료를 확인한다.
