# 2026-10-30 로봇 충돌 사전 검사 구현

## 요청과 범위

사용자 요청: 충돌 검사부터 구현한다. [[로봇 충돌 검사 범위와 차단 정책]]에 따라 로봇-환경 간 보수적인 샘플 검사를 추가한다. [[형상 경계와 OBB 충돌 검사]]와 [[궤적 샘플링과 충돌 사전 검사]]가 직접 사용한 개념이다.

## 구현

- `core/collision.py`: OBB, AABB broad phase, 15축 SAT, smoothstep 궤적 샘플링, 실행 차단 예외.
- `collision_check.py`: 실제 합성 USD에서 형상별 박스 추출, FK 변환, 로딩·언로딩·기계 검사 중 대기 자세 비교, 최초 잠재 간섭 보고서.
- `extension.py`: `Build Scene`에서 검사하고 잠재 간섭이면 장면 준비/시작을 차단한다. 실패 후 `Start`에서도 이유를 유지한다. 재빌드 시 보고서를 초기화한다.
- `scripts/check_collisions.py`, `.ps1`: Kit/GPU 없이 실제 자산으로 검사하고 JSON/Markdown 결과를 남긴다. 종료 0은 샘플 간섭 없음, 2는 잠재 간섭, 1은 실행 오류다.
- `tests/test_collision.py`, `tests/test_collision_usd.py`: 수학 경계 사례, 중간 경로 간섭, USD 단위·회전·인스턴스·가시성, 실제 자산과 장애물 주입 검증.
- `scripts/verify_collision_preflight.py`, `.ps1`: 실제 Kit의 정상 시작·장애물 차단·재빌드 복구 검증.

## 재현

```powershell
.\scripts\check_collisions.ps1
.\scripts\check_collisions.ps1 -MarginMm 2
python -m pytest tests -q
.venv-cad\Scripts\python.exe -m unittest discover -s tests -p test_collision_usd.py -v
.\scripts\verify_collision_preflight.ps1
```

기계 USD와 로봇 USD가 필요하다. 로봇 USD가 없으면 `fetch_robot.ps1`와 `urdf_mesh_to_usd.ps1`로 생성한다. CAD Python의 usd-core 버전과 입력 자산·핵심 소스 SHA256은 CLI 보고서에 기록한다.

## 검증 결과

초기 실측 `results/collision/20261030_initial/report.json`: USD 26.11, 로봇 박스 34개, 환경 박스 37개. 로딩 608개·언로딩 553개·검사 중 대기 1,379개, 합계 2,540개 자세에서 잠재 간섭 0건이다. 단위/인스턴스 등 USD 테스트 5개가 통과했고 실제 경로에 장애물 삽입 시 차단을 확인했다.

PowerShell 래퍼의 첫 실행 `results/collision/20261030_verified/`에서는 double 문자열 변환의 반올림으로 시간 간격이 미세하게 줄어 샘플이 2,543개가 됐다. 잠재 간섭은 0건이었다. 래퍼의 숫자 전달을 round-trip 문자열로 수정했다. 입력 자산·핵심 소스 SHA256도 보고서에 기록한다.

수정한 PowerShell 래퍼의 최종 실행 `results/collision/20261030_final/`은 기본 설정과 동일한 2,540개 자세에서 잠재 간섭 0건이었다.

재검증 `results/collision/recheck_20261030/`에서는 동일한 입력 자산·핵심 소스 SHA256으로 시간 간격 1/240 s, 회전 증가량 0.5도를 적용했다. 로딩 1,208개·언로딩 1,099개·검사 중 대기 2,646개, 합계 4,953개 자세에서 잠재 간섭 0건이었다. 실제 Kit 재검증 `results/interview/collision/20261030_232814/`도 정상 시작·장애물 차단·재빌드 복구에 통과했고 종료 코드 0, watchdog 시간 초과 없음이었다.

실제 Kit 검증 `results/interview/collision/20261030_231803/report.json`은 통과했다. 기본 crown 장면 Build/Start 정상, 로딩 경로의 도구 위치에 60 mm 장애물 삽입 후 Build/Start 차단, 장애물이 없는 재빌드 후 시작 복구를 확인했다. 최초 잠재 간섭은 로딩 0.364285714 s에서 양쪽 그리퍼와 주입 장애물의 형상 쌍 2개다. 테스트 전용 주입이며 실제 자산/기본 배치는 바꾸지 않았다. 프로세스 종료 코드 0, watchdog 시간 초과 없음이다.

수학 테스트 12개와 CAD Python의 USD 테스트 5개가 통과했다. 최종 전체 core 회귀는 119 passed, 5 skipped이며, 시스템 Python에 usd-core가 없어 건너뛴 5개는 CAD Python에서 별도로 모두 통과했다. Kit 테스트는 비전을 끄고 실행했으며 이번 충돌 검사가 비전 정확도를 다시 검증한 것은 아니다. 테스트의 일회용 run CSV는 기존 산출물 정책에 맞춰 `.gitignore`에서 제외한다.

## 한계

박스의 과대 경계로 오탐이 가능하다. 샘플 사이 간섭은 놓칠 수 있다. 자체 충돌·제품·수동 티칭·연속 경로는 검사하지 않는다. 현재 기본 궤적의 샘플 결과를 실제 설비의 안전성 검증으로 해석하지 않는다. 장면을 편집하면 재검사가 필요하다. 기구학·형상 원본 자산과 기존 동작 시간표는 수정하지 않았다.
