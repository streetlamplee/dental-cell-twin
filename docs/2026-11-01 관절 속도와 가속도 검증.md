# 2026-11-01 관절 속도와 가속도 검증

후속 상태: 아래는 수정 전 시간표의 진단 기록이다. 발견한 속도 초과·초기화 불연속은 [[2026-11-01 검사 셀 복귀와 속도 기반 시간 재배분]]에서 수정했다. 가속도 제한 누락은 여전히 남는다.

## 요청과 구현

요청: 현재 관절 속도·가속도를 검증한다. 로봇 로딩/언로딩 각 2초와 검사 기계 전체 8.2초의 현재 시간표를 조사했다. 런타임의 이송·기계 동작·설정·원본 자산은 변경하지 않았다.

- `core/motion_limits.py`: [[smoothstep 궤적의 속도와 가속도]]의 구간 최대값, [[URDF 운동 제한의 검증 범위]]에 따른 판정, 구간 끝의 위치 불연속/continuous 각도 래핑 분류.
- `scripts/check_joint_rates.py`, `.ps1`: 원본 로봇 URDF 해시와 kinematics 일치 검사, 실제 궤적 생성, 런타임 평가 함수와 수치 미분 대조, JSON/Markdown 보고서.
- `tests/test_motion_limits.py`: 해석적 최대값, 시간 스케일링, 방향/단위, 중간 구간의 초과, 누락/잘못된 제한, 위치 불연속과 각도 래핑 검사.

실행: `.\scripts\check_joint_rates.ps1`. 시스템 Python + numpy를 사용하며 Kit/USD/GPU가 필요 없다. 원본 로봇 URDF는 `fetch_robot.ps1`로 준비한다. 종료 0은 전체 확인/이내, 2는 제한 초과/불연속, 3은 제한 누락, 1은 실행 오류다.

## 현재 확인 결과

로봇 팔 6축은 선언된 속도 제한 이내였다. 가장 큰 회전 속도는 로딩 joint6의 15.481433 rad/s다. 이는 실장비 사양 검증이 아니라 URDF 선언값과의 비교다.

X/Y 초과는 기계 구간 1(2.0~2.45초)과 11(5.75~6.2초)에서 발생한다. 해당 구간의 X축 속도 제한만 만족시키려 해도 구간 시간이 0.45초에서 최소 2.181초가 되어야 한다. 가속도 제한이 없으므로 이를 최종 적합 시간표로 해석하지 않는다. 자동 시간 재배분은 하지 않았다.

모든 축에 가속도 제한이 없어서 가속도 크기는 계산했지만 적합성은 판정할 수 없다. 계산된 최대 구간 가속도는 X 4.308148 m/s², Y 1.510370 m/s², 로딩 joint6 254.988302 rad/s², 그리퍼 각 축 2.0 m/s²다.

## 추가 발견: 사이클 끝의 위치 불연속

`CellCycle.pose_at(cycle_s)`는 마지막 언로딩 자세가 아니라 초기 로딩 자세를 반환한다. 따라서 X축에 +0.2908 m 위치 점프가 생긴다. 그 직전의 상태에서 빈 셀/다음 사이클로 바뀌어도 같은 복귀 문제가 남는다. 이 구간은 유한한 연속 속도·가속도로 설명할 수 없으므로 위 표의 구간 최대값에서 제외하고 전체 상태를 `discontinuous`로 기록했다. C축의 -2π 변화는 같은 물리 방향의 각도 래핑으로 별도 표시했다.

해결에는 복귀 이동의 명시적 시간/궤적과 속도·가속도 제한에 따른 시간 배분이 필요하다. 이번에는 검증 결과를 남기고 기존 동작을 유지한다. 기존 [[2026-10-30 로봇 충돌 사전 검사 구현]]의 샘플 간섭 없음 결과를 속도·가속도 또는 복귀 경로의 적합성 근거로 해석하지 않는다.

## 증거와 확인

최종 재검증 보고서는 `results/joint_rates/20261101_final_recheck/report.json`, `report.md`다. 입력 원본·핵심 소스 SHA256을 기록했다. 초기 보고서는 구간 내부 제약만 조사했고, 최종 보고서에서 끝점 초기화의 불연속을 추가 검증했다. 최종 재검증에서도 같은 결과를 얻었고 종료 코드 2(실행 오류가 아닌 위치 불연속/제약 초과 판정)를 확인했다. 최종 재검증 보고서의 상태를 기준으로 한다.

실제 `ArmTransfer.state()`와 `CellCycle.pose_at()`를 각 구간의 u=0.25/0.5/0.75에서 수치 미분했다. 최대 정규화 오차는 속도 약 1.78e-6, 가속도 약 1.51e-8로 허용오차 1e-5 이내였다. 구간 끝 가속도 최대값은 해석적 편측 극한으로 계산했다. 경계 자체의 위치 점프는 따로 검사했다.

추가 단위 테스트 20개 통과. 전체 회귀는 139 passed, 5 skipped였다. 건너뛴 항목은 시스템 Python에 usd-core가 없는 기존 USD 충돌 테스트 5개이며 이번 검증은 Kit/USD에 의존하지 않는다. `check_interview_artifacts.ps1`에서 Python 80개 파일의 구문과 노트 15개의 frontmatter/wikilink 검사가 통과했다. `git diff --check`도 통과했다.
