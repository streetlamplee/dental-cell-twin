# 2026-11-01 검사 셀 복귀와 속도 기반 시간 재배분

## 요청과 변경

사용자가 앞선 검증에서 제안한 복귀 궤적 추가와 속도 기반 시간 재배분을 진행하도록 요청했다. [[검사 셀 복귀와 시간 배분 정책]]에 따라 기존 관절 공간 smoothstep 경로의 시간만 늘리고, 언로딩 뒤 초기 자세로 돌아가는 빈 셀 복귀 구간을 추가했다.

- `core/urdf_model.py`: 원본 URDF 속도 제한을 Joint 및 kinematics JSON에 보존한다. 이전 JSON의 속도 누락은 None으로 읽는다.
- `assets/cad/teeth_mill.kinematics.json`: X/Y/Z 선언 속도 0.1 m/s를 추가했다. 원본 URDF·CAD 형상은 바꾸지 않았다.
- `core/motion_limits.py`: [[smoothstep 궤적의 속도와 가속도]]에 따라 최소 이동 시간을 늘리는 함수. 미확인 제한을 생성하지 않는다.
- `core/cell_cycle.py`: 이동·파킹 구간별 시간을 계산하고 복귀 구간, `return_start`, `return_duration_s`를 추가한다. 최종 keyframe이 초기 자세와 정확히 일치한다.
- `inspection_cell.py`, `extension.py`: RETURNING 상태를 표시하고 제품을 출구에 고정한다. 로봇은 대기한다. 기존 ConveyorSim은 늘어난 전체 cycle_s와 이동된 view_times를 그대로 사용한다.
- `tests/`: 실제 기계의 속도 제약, 끝점 연속성, 두 제품의 셀 예약·검사/배출 순서, 속도 메타데이터 왕복을 검증한다.
- `scripts/verify_retimed_cycle.py`, `.ps1`: 실제 Kit에서 crown 2개, 적용된 관절 변화율, 복귀 중 제품 위치, 다섯 시점 프레임과 전체 완료를 검증한다.

## 재현과 결과

```powershell
.\scripts\check_joint_rates.ps1
.\scripts\check_collisions.ps1
python -m pytest tests -q
.venv-cad\Scripts\python.exe -m unittest discover -s tests -p test_collision_usd.py -v
.\scripts\verify_retimed_cycle.ps1
```

속도 검증의 전체 상태는 `incomplete`(종료 3)이다. 알려진 속도 초과나 위치 점프가 남았다는 뜻이 아니라, [[URDF 운동 제한의 검증 범위]]에서 다룬 모든 축의 가속도 제한과 기계 B/C축 속도 제한이 없기 때문이다. 원본 로봇 URDF와 kinematics 비교도 수행한다.

수정 직후 `results/joint_rates/20261101_retimed/`에서 알려진 속도 이내와 끝점 연속성을 확인했다. 최종 재검증은 `results/joint_rates/20261101_retimed_final/`이며 전체 상태는 미확인 제한 때문에 incomplete, 모든 알려진 속도 제한은 within, 모든 끝점 초기화는 continuous였다. 최종 보고서의 입력·핵심 소스 SHA256도 현재 파일과 대조했다.

최종 충돌 검사 `results/collision/20261101_retimed_final/`는 복귀 경로를 포함한 3,359개 자세에서 잠재 간섭 0건이었다. 전체 core 147 passed, 5 skipped, CAD Python USD 테스트 별도 5개 통과. 시스템 Python에 usd-core가 없어 건너뛴 5개를 CAD Python에서 별도로 수행했다.

실제 Kit 검증은 `results/interview/retiming/20261101_225857/report.json`과 `process.json`이다. 종료 코드 0, watchdog 시간 초과 없음. 적용 관절값의 시뮬레이션 시간별 변화율 2,347개를 확인했고, X/Y/Z 최대 관측값은 각각 0.09999948/0.03505734/0.01316928 m/s였다. 복귀 중 제품 출구 위치 523개 샘플이 일치했다. 두 제품의 LOAD/UNLOAD 시각은 각각 2.84→18.864초, 18.864→34.888초로 모든 사이클이 16.024초였고 다음 제품의 시작은 앞 제품의 셀 해제 이후였다.

제품당 다섯 시점 프레임과 합친 판정 행을 모두 확인했다(총 캡처 10장, 검사 행 12개). 2/2 분류·배출, 타임아웃/late result/stale frame 모두 0, 전체 실행 complete였다. 이 2개 제품은 런타임 연동 확인용으로 일반적인 비전 정확도나 포화 처리량 검증을 뜻하지 않는다. 구문·frontmatter·wikilink 검증도 통과했다.

## 남은 한계

실장비 가속도 제한·B/C 속도·토크·부하·jerk는 확인하지 못했다. 새 복귀도 형상 박스와 이산 샘플의 간섭 검사를 사용하므로 메시 정밀 충돌·연속 충돌·제품 자체 충돌을 보장하지 않는다. 복귀 중 출구 제품은 벨트 흐름에 다시 참여하지 않고 셀의 예약 제품으로 남는다.
