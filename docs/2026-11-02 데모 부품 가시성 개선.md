# 2026-11-02 데모 부품 가시성 개선

## 요청

영상에서 작은 부품이 잘 보이지 않는 문제를 전체 구도와 별도 확대 화면으로 개선하고 새 영상을 렌더링한다.

## 구현

- `scripts/record_clips.py`: [[부품 추적 확대 렌더링]]을 위한 제품 추적 카메라와 독립 640×480 확대 뷰포트 추가. 검사 뷰포트를 별도로 유지해 다음 제품 검사와 대상 제품의 배출 확대를 동시에 렌더링.
- 이동·로봇 집기·내려놓기·불량 배출 화면에 400px 너비의 실시간 확대 화면 합성.
- 로봇 작업의 메인 카메라 초점거리를 24mm에서 30mm로 변경.
- 검사 화면에는 기존 검사 저장 이미지 확대 패널 유지.
- [[다중 뷰포트 캡처와 화면 합성]]으로 캡처 콜백 쌍이 모두 도착한 뒤 저장하며 실패 또는 미완료 요청은 녹화 실패로 처리.
- 부품 실물 크기와 시뮬레이션 동작은 유지.
- 기본 녹화는 seed 3의 첫 제품(미가공 형상 결함)을 따라가도록 변경. 다음 제품도 투입해 첫 제품의 불량 배출 애니메이션이 끝나기 전에 시뮬레이션이 종료되는 것을 방지.
- 녹화 프로세스에서 렌더 모드를 `RaytracedLighting`으로 명시하고 패스 트레이싱 샘플 수를 1로 제한해 사용자 렌더 설정에 따른 과도한 부하를 방지.
- 배치 실행 시 Legacy 실시간 렌더러를 명시적으로 활성화하고 사용자 설정 읽기·저장을 비활성화한다. 비활성화된 렌더 모드를 스크립트에서 선택하면 `RealTimePathTracing`으로 되돌아가는 것을 실행 로그로 확인했다.
- 녹화 실행만 고정 시뮬레이션 스텝을 1/30초로 설정하고 매 업데이트를 캡처해 30fps 실제 속도로 출력한다. 일반 앱의 기본 스텝은 유지한다.
- 최종 메인 렌더와 출력은 1280×720이며, 부품 확대 소스는 640×480이다. 실시간 패널은 중앙 16:9 영역을 400×225로 표시해 컨베이어 위 제품을 가리지 않는다. 60Hz로 동작하는 티칭 재생은 매 두 업데이트 캡처한다.
- 제품 하위 카메라를 만들고 초기 12개 렌더 프레임을 기다린 후 녹화를 시작한다. 이동 예측 없이 고정 로컬 변환으로 연속 이동을 따라간다.
- `render.json`에 카메라 해상도, 녹화 프레임 수, 렌더 모드, 캡처 오류 수 기록.
- `scripts/record_clips.ps1`: 장면별 클립 외에 통합 MP4 생성, 인코딩 실패 감지, 프레임 삭제 전 경로 검증 추가.
